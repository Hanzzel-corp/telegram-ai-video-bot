# Bot de Telegram para Generación de Video con IA

Este es un bot de Telegram que utiliza modelos de IA para generar videos cortos a partir de descripciones de texto.

## Funcionalidades
* **Texto a Video:** Envía un prompt y recibe un video animado.


## Instalación
1.  Clona este repositorio.
2.  Crea un entorno virtual: `python -m venv env`
3.  Activa el entorno: `.\env\Scripts\activate`
4.  Instala las dependencias: `pip install -r requirements.txt`
5.  Crea un archivo `.env` y añade tu token de Telegram.
